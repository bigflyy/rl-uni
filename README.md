# Курьер в городе со случайным трафиком

Лабораторная работа: среда с неопределённостью и сравнение трёх стратегий доставки, заданных вручную (без обучения).

Карта — центр Павлодара из OpenStreetMap, переведённый в сетку 160 × 160 (0 — дорога, 1 — препятствие). Курьер едет из одного из трёх стартов к общей цели. Шесть источников с вероятностью `p` на каждом шаге выпускают машины, которые случайно блуждают 15–150 шагов; встреча курьера с машиной — авария.

## Стратегии

| Стратегия | Идея |
| --- | --- |
| Исследователь | идёт в новые клетки, уходит от близких машин |
| Нетерпеливый кратчайший | кратчайший путь (BFS) + штраф за близкие машины |
| Осторожный объезд | путь Дейкстры в обход источников машин, ждёт приближающиеся машины |

Сравнение: `p` = 0; 0,005; 0,02; 0,05, три старта, 5 seed по 100 поездок — всего 18 000 поездок. Метрики: доля доставок и среднее число шагов успешной доставки.

## Запуск

```bash
python -m pip install -r requirements.txt
python -m notebook courier_project.ipynb   # затем Run All
```

Нужен Python 3.11+. Карта и данные OSM уже в `data/`, интернет не нужен. GIF в репозиторий не включены и создаются при запуске ноутбука; `python build_map.py` нужен только для перестройки карты.

## Файлы

- `courier_project.ipynb` — среда, стратегии, эксперимент, графики, GIF
- `build_map.py` — построение карты из OSM
- `data/` — исходные данные и сетка карты
- `results/` — CSV с результатами и графики
- `outputs/` — отчёт (PDF, LaTeX) и презентация
