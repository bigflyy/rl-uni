# Разработка среды с неопределенностью

## Запуск

1. Распакуйте архив в любую папку, сохранив структуру файлов.
2. Установите Python 3.11 или новее.
3. В папке с `courier_project.ipynb` выполните `python -m pip install -r requirements.txt`.
4. Запустите `python -m notebook` или откройте папку в VS Code. Откройте `courier_project.ipynb`, выберите этот Python и нажмите Run All.

Карта и исходный файл OpenStreetMap уже находятся в `data/`. Для обычного запуска интернет и отдельная команда построения карты не нужны. Скрипт `build_map.py` позволяет построить карту заново, если потребуется её изменить.

Ноутбук выполняет 18 000 поездок, обновляет CSV, графики, изображения маршрутов и семь GIF в `results/`. В архиве лежат уменьшенные GIF для просмотра; после Run All ноутбук заменит их полноразмерными версиями. Время выполнения зависит от компьютера.

## Файлы

- `courier_project.ipynb` - среда, стратегии, эксперименты и визуализации.
- `build_map.py` и `data/` - код и исходные данные карты.
- `results/` - готовые результаты для просмотра до запуска.
- `outputs/courier_lab_report_full.pdf` - полный отчёт.
- `outputs/courier_lab_presentation_full_with_tables.pptx` - полная презентация с анимациями.
- `outputs/courier_lab_report_full.tex` - исходник отчёта.
