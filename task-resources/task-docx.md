Реализация взаимодействия агента со средой

Цель работы – получить навыки создания среды с неопределённостью. 
Задачи – Создать среду, в которой имеются агент-доставщик полезного груза по городу.
Для этого необходимо сформировать карту (Берёте карту реального города и по изображению дорог города получаете карту, делаете только одно изменение – по дороге можно ехать в двух направлениях, т.е. у нас нет односторонних и двухсторонних дорог), в которой будет перемещаться агент. Пример карты для одного агента в файле “citymap.txt”. Минимальные размеры карты 50 x 50.
Пояснения к карте:
0 (а также 2, 3, 4) – области на карте, куда агент может попасть (дорога).
1 – на карте отмечены препятствия, куда агент не может попасть (стены). 2 – место, с которого агент начинает движение по карте.
3 – места, с которых с определенной вероятностью выходят другие транспортные средства (вероятность этого мала, например 0.02).
4 – Область, в которую должен попасть агент.
На каждой итерации:
Агент делает одно из действий: влево, вправо, вверх, вниз или остановка. Транспортные средства тоже делают одно из этих движений. Для каждого транспортного средства генерируется движение в область, куда можно попасть (0), также применяется следующее условие: c вероятностью 70% двигается в направлении, которое было предыдущем шаге если следующая такая область доступна, если достигает развилки, то с равной вероятностью выбирает одно из направлений движения, включая обратно, если транспортное средство начинает движение из тупика, то выбирается единственное направление – выход из тупика). Если агент наступает в область, где уже есть транспортное средство, то происходит авария и завершение эпизода.
При начальном выходе из области 3 для транспортного средства генерируется число количество шагов (случайная величина от 15 до 150). В течение этого числа итераций транспортное средство двигается, а по достижению этого числа убирается из карты (припарковывается или заезжает в гараж 😊).
Установить на карте 3 места, из которых будет выезжать агент. Задать три стратегии движения агента для достижения целевого состояния.  Исследовать как будет изменяться средняя скорость доставки, вероятность успеха агентов в зависимости от скорости генерации других транспортных средств. Провести не менее 100 экспериментов с одним random_state (Seed)) для каждого начального места агента и для каждой стратегии. Взять не менее 5 разных random_state (Seed). Получить boxplot демонстрирующие результаты моделирования - скорость доставки, вероятность успеха агента.
Написать отчет.
Описание отчета.
1. Карта области, где перемещается агент. Спутниковый снимок части города (или другого сервиса), которая использовалась для моделирования и получения карты.
2. Графики, иллюстрирующие изменение среднего количества шагов агента в зависимости от скорости генерации других транспортных средств.
3. Диаграммы размаха, демонстрирующие результаты моделирования - скорость доставки, вероятность успеха агента
4. Визуализация перемещения агентов по карте в виде анимированного файла или набора карт на каждой итерации после процесса настройки сети.
5. Программный код с комментариями.
6. Выводы
